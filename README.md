# Personal To-Do List Manager

A terminal-based task management application that allows users to fully manage personal to-do items from the command line through an interactive menu system. The program supports end-to-end task operations, including creating tasks with a title and optional details, viewing tasks in a clear numbered list, editing task content, deleting tasks, and marking tasks as complete or incomplete. Similar to Google Keep the goal is to create an resource efficient application that will run in a terminal. Tasks are organized for easier tracking using both date-based and category-based grouping, allowing users to review work by schedule and by type. The application uses file-based storage to persist all task data between sessions, ensuring that tasks remain available after the program closes. The interface is designed to be simple, fast, and beginner-friendly, with consistent prompts and straightforward navigation so users can manage their tasks efficiently without needing a graphical interface.
